Where the memory goes

Three things occupy memory when a model is loaded: the weights themselves, the KV cache that holds the conversation, and the runtime's own working buffers. Only the first is fixed — the KV cache grows with every token in your context.

Can an M4 Pro 48GB Mac run DeepSeek V4 Flash?
No. At Q4_K_M it needs about 175.7 GiB, and an M4 Pro 48GB Mac has roughly 40.8 GiB available for a model after macOS takes its share.
How fast is DeepSeek V4 Flash on an Mac?
Around 1 tokens per second. Token generation on Apple Silicon is limited by memory bandwidth, and this machine has 273 GB/s.
How much memory does DeepSeek V4 Flash need?
166.0 GiB for the weights at Q4_K_M, plus 0.7 GiB for an 8K-token KV cache and about 9.1 GiB of runtime overhead — 175.7 GiB in total.
